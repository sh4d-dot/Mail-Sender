# MAIL SENDER
Very simple mail sender using Python's SMTP library only. this is a simple script used for sending emails through any services continuously.
______________________________________________________________________________________________________________________________________________
# How to use it?
- You must have a seperated file named 'message.txt' as well as 'password.txt' in the script folder to hold your email password and your mail messages. This is crucial for the script to work properly!
- For the password field, you must have an APP PASSWORD to log into your email. if you use gmail, this is how to make an APP PASSWORD: https://support.google.com/mail/answer/185833?hl=en
